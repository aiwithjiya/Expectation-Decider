# 🚀 Expectation Decider

## 📌 Project Overview

Expectation Decider is a probability and statistics project based on student academic data.

The main objective of this project is to analyze probability patterns and understand the factors related to whether a student passes a competitive mathematics exam.

The dataset contains information about 200 students, including study hours, attendance, group discussion participation, previous test scores, and final exam results.

## 📁 Dataset

The dataset contains the following columns:

| Column                | Description                                      |
| --------------------- | ------------------------------------------------ |
| `study_hours`         | Number of hours a student studied per week       |
| `attendance`          | Percentage attendance in lectures                |
| `group_discussion`    | Participation in group discussions (Yes/No)      |
| `previous_test_score` | Marks out of 100 from the previous internal test |
| `final_exam_pass`     | Final competitive exam result (Pass/Fail)        |

## 🔍 Tasks Covered

### 1. Understanding the Basics

* Explanation of Probability
* Key probability terminology
* Probability examples from the dataset

### 2. Types of Events

* Empirical probability
* Theoretical probability
* Step-by-step calculations

### 3. Random Variable & Probability Distribution

* Defined a random variable for the number of students passing out of 3 randomly selected students
* Created a probability distribution table
* Calculated mean
* Calculated variance
* Created a probability distribution chart

### 4. Venn Diagram

Created a Venn diagram for:

* Students studying more than 10 hours per week
* Students having attendance above 80%
* Students satisfying both conditions

### 5. Contingency Table & Probability Calculations

Created a contingency table for:

`group_discussion` vs `final_exam_pass`

Calculated:

* Joint probability
* Marginal probability
* Conditional probability

### 6. Understanding Relationships

Interpreted conditional probability in simple language and analyzed whether group discussion participation and passing the exam are independent, dependent, or mutually exclusive events.

### 7. Bayes Theorem

Applied Bayes Theorem using the historical probabilities provided in the project question to calculate the probability that a student passed the exam given that the student had high attendance.
